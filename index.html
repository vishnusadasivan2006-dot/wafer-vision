🔄 Workflow

How WaferVision Works

A streamlined six-step process from wafer image capture to actionable inspection reports.

01

Image Acquisition

Wafer images are captured via file upload, batch upload, or live camera feed connected to an external microscope. The system accepts standard wafer map formats and real-time video streams.

02

Preprocessing & Enhancement

Images undergo normalization, resizing, and augmentation pipelines. OpenCV processes the raw wafer maps to ensure optimal input quality for the neural network models.

03

Model Inference

The selected model (ResNet18 or Ensemble) performs forward-pass inference. The Ensemble model combines ResNet18+CBAM, EfficientNet-B0, and DenseNet121 predictions through weighted averaging for maximum accuracy.

04

Defect Classification & Probability Analysis

The model outputs class probabilities across all 9 defect categories. The highest probability class is selected as the detected defect, with confidence values displayed (e.g., Donut: 98%, Loc: 2%).

05

Heatmap Generation & Localization

Grad-CAM generates defect localization heatmaps showing exactly where the defect occurs. Red/Yellow regions indicate defect locations, while Blue regions indicate normal areas.

06

Alert, Report & Archive

If a defect is found and email alerts are enabled, the system sends an immediate notification to the user. Results are saved to the inspection history database and a downloadable PDF report is generated.
